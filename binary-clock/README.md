# 二进制钟楼 · Binary Clock Tower

根据照片里的二进制时钟制作的可交互数字版本。无需构建、无需联网，全部样式、SVG、脚本都内联在一个 HTML 文件里。

## 打开

直接双击 `index.html`，或把它拖进浏览器。推荐 Chrome / Edge。

- 默认显示**本地当前时间**，每秒更新。
- 页面加载后同时驱动四处显示：顶部日晷、六列四位 BCD 灯阵、指针钟、右侧十进制读数。
- 宽屏与手机屏幕各有对应布局。

## 顶部日晷怎么看

保留上一版白色扇形日晷的图样，包括放射状时刻线、9 / 3 侧标、10–2 底标和顶部三个黑点，不重绘成新的圆盘。

**读法**

- 盘面左上角显示准确的本地时间（例如 `13:28`），右上角显示时段（黎明 / 上午 / 正午 / 午后 / 黄昏 / 夜晚 / 深夜）与 `DAY` / `NIGHT` 百分比；左上说明卡也会给出同样的读数。
- 太阳在 **09:00–15:00** 之间沿扇面底边移动，依次对准原图的 **9 → 10 → 11 → 12 → 1 → 2 → 3** 刻度：例如 10:54 的太阳位于 `11` 正上方，13:28 位于 `1` 与 `2` 之间。
- 09:00 之前和 15:00 之后，太阳沿扇面左右边界升起或落下，不再落在 9–3 的底边刻度上；这时以盘面左上角的数字时间为准。
- 夜间由月亮沿底边移动；扇面左上的时间与右上的阶段仍与本地时钟同步。
- 日晷刻度是照片原图的 9–3 日光刻度，不是完整的 24 小时刻度；准确时间始终以盘面左上角、左上说明卡和下方二进制灯阵为准。

**动态效果**

- 太阳与月亮在黎明、黄昏时交棒；从顶部汇聚点射出一束同步光束，白昼偏暖金，夜间偏冷蓝。
- 白昼时面板带一点暖色，夜间覆一层淡蓝夜色，晨昏加入暖色，原图线条与数字始终保留。
- 日晷使用固定的 **06:00 / 18:00** 作为图形化白昼分界，不依赖地理位置，也不计算真实日出日落时间。

## 二进制灯阵读法

每一列四盏灯，自上而下代表 **8 · 4 · 2 · 1** 四个位，一列表示一个十进制数字（0–9）。

六列从左到右依次是：

```
时的十位 | 时的个位 | 分的十位 | 分的个位 | 秒的十位 | 秒的个位
```

照片中的 `13:28:25` 对应：

```
0001 0011 · 0010 1000 · 0010 0101
```

黑色面板里亮灯表示 1，暗灯表示 0；右侧黑色读数卡会给出同样的十进制时间、日期与 BCD 码，方便对照。

## 固定到某个时刻

在地址后加 `?t=HH:MM:SS`，可以冻结到任意时刻：

```
index.html?t=13:28:25
index.html?t=23:13:44
```

再加 `&static=1` 会关闭入场动画，便于截图：

```
index.html?t=13:28:25&static=1
```

不带参数打开时始终使用真实的本地时间。

## 实现说明

- 场景用 CSS 渐变、内联 SVG 和分层阴影重建了照片里的黄色钟塔、白色建筑立面、栏杆与窗格。
- 指针钟的面盘纹样、刻度与指针均为 SVG；指针、日晷与数字灯阵共用同一个时间源。
- 日晷保留旧稿的扇形线稿，只用 SVG 叠加太阳、月亮、光束、时间读数和暖/冷色罩；09:00–15:00 的太阳位置对齐原图的 9–3 刻度，其余时段沿左右边界升降。
- 灯珠使用径向渐变、锥形纹理和分层阴影模拟暗灯与发光的 LED；切换时有短暂过渡。
- 时间计算使用 BCD：每列取一个 0–9 的数字，对应四位从 8 到 1 的位权，因此不存在二进制时钟常见的“跳变歧义”。
- 侧卡说明与读数会随窗口尺寸重新排版；移动端保留可读的灯阵和 8·4·2·1 提示。

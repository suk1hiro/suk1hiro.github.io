# 迷你数独 · Mini Sudoku

一个参考 [minisudoku.com](https://minisudoku.com/) 风格做的网页版数独：以 **6×6 迷你数独**为主打，
同时支持**经典 9×9**。零依赖静态站点，双击 `index.html` 就能玩，不需要 Node、不需要安装、不需要注册。

```
sudoku/
├── index.html          游戏主页面
├── archive.html        往期题目档案
├── css/main.css        设计系统与全部样式
├── js/
│   ├── core.js         存档、设置、日期与轻提示
│   ├── generator.js    题面生成器（种子化、解唯一）
│   ├── game.js         对局引擎（落子、标记、冲突、撤销、提示、计时）
│   ├── stats.js        完成记录、最佳成绩、连续打卡
│   ├── ui.js           视图层：棋盘 / 键盘 / 状态栏 / 侧栏
│   ├── app.js          主控制器：模式路由、交互、结算
│   └── archive.js      档案页逻辑
└── tools/              开发期测试工具（不影响线上运行）
```

## 玩法与功能

**两种规格**

| 规格 | 宫格 | 数字 | 难度（已知数个数） |
| --- | --- | --- | --- |
| 6×6 迷你 | 2 行 × 3 列 | 1–6 | 入门 ≈16、进阶 ≈14、困难 ≈12、专家 ≈10 |
| 9×9 经典 | 3 行 × 3 列 | 1–9 | 入门 ≈37、进阶 ≈31、困难 ≈27、专家 ≈24 |

**四种模式**

- **每日**：每天一道固定题，同一天任何设备都是同一题面。难度按星期轮换，周三最轻松、周末偏难。
- **每日挑战**：与每日题同一个题面种子，但固定为专家难度。
- **不限**：随时开局，难度自选，进度自动保存，可随时切回来继续。
- **往期**：按日期复现过去每一天的题目，完成记录会合并到当天的打卡里。

**URL 约定**（方便直接分享某一期）

| URL | 含义 |
| --- | --- |
| `/` 或 `/index.html` | 今天的每日题 |
| `?mode=hard` | 每日挑战（同题面，专家难度） |
| `?mode=practice&difficulty=expert&size=9` | 不限模式，指定难度与规格 |
| `?mode=archive` | 打开往期列表页 |
| `?mode=archive&date=2026-09-20` | **直接开那一期的题目**（不再跳转） |
| `?date=2026-09-20` | 每日题始终按“今天”算，带 date 但不带 mode 会被忽略，请用上面那行 |

> 早前 `mode=archive` 同时表示“列表页”和“玩某一期”，导致点往期卡片时
> 在题目页与档案页之间反复弹跳；现已拆开：带 `date` 就是玩那一期，不带才进列表。

**配色主题（5 套）**

侧栏「外观与偏好 → 配色主题」里点色卡即可整套换色，选择会记住、刷新后保留：

| 主题 | 取向 |
| --- | --- |
| **清爽**（默认） | 浅灰蓝底 + 蓝色强调，干净通用 |
| **暖纸** | 米色纸面 + 酒红强调，长时间看不刺眼 |
| **糖果** | 柔和紫粉渐变，偏活泼 |
| **暗夜** | 深色底 + 提亮的蓝，夜间护眼 |
| **高对比** | 纯黑白 + 高饱和强调，方形硬边，强光或视力不佳时更清楚 |

主题通过 `<html data-theme="...">` 切换：所有颜色都定义在 [main.css](css/main.css) 顶部的令牌里，
主题块只覆盖令牌，业务规则里不出现任何硬编码颜色（`tools/validate-static.mjs` 会强制这一约束）。
新增主题只需在 CSS 加一个 `[data-theme='xxx']` 块、在 [core.js](js/core.js) 的 `S.THEMES` 里登记一行。

同时同步了 `color-scheme`（滚动条、原生控件跟着变色）与 `<meta name="theme-color">`（移动端地址栏）。

**界面排版**

- 宽屏双栏：左侧棋盘区（状态行 / 棋盘 / 难度 / 操作 / 数字键盘），右侧信息栏；窄屏自动变单栏。
- 单栏下棋盘卡片限宽 580px 居中，避免平板宽度下控件被拉得过宽。
- 棋盘尺寸完全由 CSS 变量按视口与规格自适应，不依赖 JS 计算。
- 所有可点目标 ≥ 44px，数字键与操作键在手机上也是大按钮。

**怎么调难度**

棋盘下方那一排「入门 / 进阶 / 困难 / 专家」**任何时候都能点**：

- 点任意难度 → 立刻开一局该难度的新题，并自动切到「不限」模式。
- 身处每日模式时，按钮上会额外标注「今日」，提示当天每日题的难度（按星期轮换）；
  点别的难度就会离开每日题，进入自由练习。
- 每日挑战固定专家难度，同样可以点任意难度转去自由练习。
- 选择会被记住，下次打开仍是上次用的难度。

四个难度的区分依据是**已知数个数**：

| 难度 | 6×6 已知数 | 9×9 已知数 |
| --- | --- | --- |
| 入门 | ≈16 | ≈37 |
| 进阶 | ≈14 | ≈31 |
| 困难 | ≈12 | ≈27 |
| 专家 | ≈10 | ≈24 |

**操作**

- 点格子选中 → 点数字键填入；重复点同一个数字键可以取消。
- **标记**：把候选数字以小字写进格子，适合做推理草稿。
- **撤销 / 擦除 / 提示 / 重来**：提示会优先挑“只剩一个候选”的格子。
- 键盘：`方向键`或`WASD` 移动、`1–9` 填入、`Backspace` 擦除、`N` 标记、`Z` 撤销、`H` 提示、`空格` 暂停、`R` 重来。

**体验细节**

- 高亮分层：同宫 → 同行同列 → 相同数字 → 选中格，一眼看清当前单元。
- 重复数字实时标红；可选的“检查错误”会直接把与答案不符的数字标红。
- 数字键显示每个数字还差几个，填满后自动变灰。
- 暂停时计时冻结，**暂停时长不计入成绩**，玩家看到的用时就是记录下来的成绩。
- 答题中途刷新页面会恢复同一道题和已填内容；切走标签页会自动暂停。
- 完成记录、最佳成绩、连续打卡天数都存在浏览器本地（localStorage），不上传任何数据。
- 适配手机：棋盘按视口宽度自适应，数字键保持 ≥44px 的点击高度。

## 题目生成算法

1. **随机种子**：`seed` 字符串经 FNV-1a 哈希后作为 mulberry32 伪随机源，因此同一种子必然复现同一道题（每日题依赖这一点）。
2. **填完整解**：随机顺序回溯填满一个合法终盘。
3. **挖空**：优先成对挖中心对称的两格，挖不动时再单格挖；**每挖一次都用求解器确认题面仍然“解唯一”**，否则立刻撤销。
4. **难度**：以目标已知数区间控制，若第一次尝试落在区间外就重新生成，最多 4 次，取最接近难度目标的一次。

求解器用“候选数最少优先（MRV）+ 最多数 2 个解就提前返回”剪枝。实测 6×6 一次生成 <2ms，
9×9 专家级最慢约 35ms，主线程直接生成不会造成可感知卡顿。

| 文件 | 用途 |
| --- | --- |
| [index.html](index.html) | 游戏主页面 |
| [archive.html](archive.html) | 往期题目档案 |

## 本地运行

> **⚠️ 不要用 DSH 的「文件预览」面板打开 `index.html`。**
> 预览面板是**文件查看器，不是应用运行环境**：它只做静态渲染、不执行页面脚本，
> 并且会盖一层自己的浮层。而棋盘、数字键、难度按钮、侧栏**全部由脚本生成**，
> 脚本不执行就只剩空壳（空白区域 + 一个 `00:00` 计时器），看起来像“界面没有可操作的东西”。
> 请用**系统浏览器**打开，下面几种方式都可以。

**方式一：一键启动（推荐）**

右键 [start.ps1](start.ps1) →「使用 PowerShell 运行」。脚本会自动找空闲端口、起本地服务、
再用默认浏览器打开，并打印出实际地址。

**方式二：直接双击**

在资源管理器里双击 [index.html](index.html)，用 Chrome / Edge 打开。
`file://` 下部分浏览器会限制 localStorage，站点已内置内存兜底，不影响游玩，
只是刷新后进度可能不保留——想要进度持久化就用方式一。

**方式三：手动起服务**

```powershell
# 任选一种，然后访问 http://127.0.0.1:8080
python -m http.server 8080
```

部署时把 `index.html`、`archive.html`、`start.ps1`、`css/`、`js/` 上传到任意静态托管即可。

## 排查“界面空白 / 点不动”

先确认打开方式（见上），再用自带的诊断页定位：

```powershell
node tools/make-diagnose.mjs      # 生成 .tmp/diagnose.html
```

用浏览器打开 `.tmp/diagnose.html`，页面底部会直接列出结论：脚本是否加载、应用是否初始化、
界面元素是否渲染、样式是否生效、以及捕获到的脚本错误。它由真实 `index.html` 注入生成，与线上页面同构。

## 测试

`tools/` 下是一组开发期脚本，用 Node 运行。Node 可执行文件用系统自带的、或 DSH 内置的
（`~/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node.exe`）。

```powershell
# 1) 静态结构校验：标签配平、id 唯一、脚本取用的 DOM id 是否存在、CSS 配平、
#    主题契约完整性（每个主题都覆盖关键令牌）、颜色是否全部令牌化、脚本加载顺序
node tools/validate-static.mjs        # 37 项

# 2) 生成器自检：解唯一、题面无冲突、同种子可复现、耗时统计
node tools/test-generator.mjs

# 3) 端到端冒烟测试：用轻量 DOM 桩件真实加载页面脚本，模拟点击走完整局
node tools/test-app.mjs               # 206 项断言

# 4) 生成浏览器自检页（校验真实布局、像素与配色，Node 桩件做不到这部分）
node tools/make-browser-check.mjs     # 然后用浏览器打开 .tmp/browser-check.html

# 5) 生成环境诊断页（界面异常时用）
node tools/make-diagnose.mjs          # 然后用浏览器打开 .tmp/diagnose.html

# 6) 修复“UTF-8 被当成 GBK 读取”造成的中文乱码（可逆，先 --dry 预览）
node tools/fix-mojibake.mjs <文件> --dry
```

`tools/test-app.mjs` 覆盖：首屏渲染、落子/撤销/擦除、铅笔标记、冲突检测、
提示与撤销后的一致性、暂停与计时（含暂停时长不计入成绩）、通关结算与打卡、
9×9 与难度梯度、5 套配色主题的切换与持久化、存档恢复、设置开关、
往期档案页与「玩某一期」不再来回跳转。

## 已知取舍

- 难度以**已知数个数**为主要指标，没有做“所需解题技巧”分级，因此同难度不同题目的实际体感会有浮动。
- 提示采用“直接给答案”而不是逐步引导，适合休闲场景；想更严格可以改成只揭示某格候选。
- 每日题按**本地时区**判定日期，跨时区旅行时“今天”会跟着设备走。
- 没有联机排行榜与账号体系，所有数据都留在本地浏览器里。
